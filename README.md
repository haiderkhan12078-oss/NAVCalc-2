# NAVCalc Interactive Concept V2

A zero-dependency, multi-page frontend concept using fictional data.

## Open locally
Open `index.html` in a browser. All pages share demo state through localStorage.

## Pages
- Overview
- NAV Workspace
- Reconciliations
- Exceptions
- Reporting
- Audit & Controls

## Demo flow
1. Run NAV close.
2. Open Exceptions and resolve the generated review item.
3. Return to NAV Workspace and approve the NAV.
4. Open Reporting, generate a report pack, then publish it.
5. Open Audit & Controls to review/export the full trail.

All fund data and controls are fictional and do not reproduce NAVCalc proprietary calculation logic.
